# Contribuindo com o SAD

Obrigado pelo interesse em contribuir com o Sistema de Avaliação de Desempenho!

## Como contribuir

1. Faça um fork do projeto
2. Crie uma branch para sua feature
3. Faça suas alterações seguindo os padrões abaixo
4. Commit suas mudanças com mensagem clara
5. Faça push para a branch
6. Abra um Pull Request descrevendo o que foi feito

## Padrões de código

### PHP

- Seguir PSR-12
- Rodar vendor/bin/pint antes de commitar
- Métodos e classes em português (padrão do projeto)

### Blade

- Indentação de 4 espaços
- Componentes do Filament quando possível

### Migrations

- Sempre com up() e down() funcionais
- Nome descritivo (create_x_table, add_y_to_z)

### Commits

- Mensagens claras em português
- Formato: Adiciona X, Corrige Y, Remove Z

## Reportar bugs

Abra uma issue com:

- Descrição do problema
- Passos para reproduzir
- Comportamento esperado vs observado
- Versão do PHP, Laravel e navegador
- Prints quando aplicável

## Sugerir melhorias

Abra uma issue com a tag enhancement descrevendo:

- A necessidade ou problema
- Solução proposta
- Alternativas consideradas

## Dúvidas

Abra uma issue com a tag question.
